# Extrait géographique de Corte

`corte.json` est un extrait des données **© OpenStreetMap contributors**, téléchargé le 28 octobre 2026 depuis [l’API cartographique OpenStreetMap](https://api.openstreetmap.org/api/0.6/map.json?bbox=9.143,42.296,9.162,42.312).

Les coordonnées des voies et des bâtiments, leurs identifiants et leurs attributs proviennent d’OpenStreetMap. Cette extraction et sa transformation en JSON compact restent disponibles sous [Open Database License 1.0 (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/). Voir aussi les [conditions et l’attribution OpenStreetMap](https://www.openstreetmap.org/copyright). L’attribution apparaît sur la carte dans l’application.

Le style SVG et les commandes sont propres à Memoria Corti. Le calcul de liaison utilise uniquement les voies connectées de l’extrait et reste indicatif ; il ne remplace pas un service de guidage actualisé. Les marqueurs désignent approximativement les bâtiments, pas leurs entrées. Le fichier local évite tout appel aux serveurs de tuiles pendant l’utilisation de la carte.
